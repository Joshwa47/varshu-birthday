VARSHU BIRTHDAY SITE — GITHUB PAGES

Upload index.html and the entire assets folder to the ROOT of a GitHub repository.
The music is assets/song.mp3. Keep the assets folder beside index.html.

To publish with GitHub Pages:
1. Open the repository Settings, then Pages.
2. Choose Deploy from a branch, select main and /(root), and save.
3. Wait for GitHub Pages to show the public site link.

Privacy note: this is a static GitHub Pages version. The 0416 keypad is a page-level surprise gate, not server-side security. The MP3, MP4, and photo poster can be opened directly by URL. Do not use this ZIP if those files must be private.
